# TI-83+ Emulated Portfolio

A nostalgic portfolio experience built as an interactive TI-83+ graphing calculator emulator. Explore projects, skills, and experience through the lens of retro computing.

## Features

- Fully functional TI-83+ emulator interface
- Project portfolio accessible via calculator menus
- Interactive demonstrations and skill showcases
- Authentic retro aesthetic with modern web technology

## Getting Started

```bash
cd ti83-emulated-portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Technology

- Web-based TI-83+ emulator
- Interactive portfolio system
- Responsive design with retro styling
