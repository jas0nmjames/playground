**Shipped 2026-11-17; release published {{PUBLISHED}}.** Tag `medianville-m1-one-day` at [`2379e72`](https://github.com/jas0nmjames/playground/commit/2379e72), the merge of [#54](https://github.com/jas0nmjames/playground/pull/54).

Medianville's first milestone, when the city was still called Halvern: one simulated day, Wednesday, March 3, 2027, in 201,753 records, and the first viewer, the night map, which draws every record as a light crossing an abstract map of the city's six districts.

- **The day:** generated on 2026-11-16 by Claude Fable 5.2 in the Claude app from the transaction generator prompt: 41,400 households, 99,694 people and 1,672 organizations, calibrated to published anchors, with the simulator that made it and 500 hand-written records.
- **The viewer:** built as a Claude artifact and brought into the repo by Claude Code, which made it load the run on its own.
- **Decided:** simulate, don't write; settle the day in time order against each household's money; real federal names, invented local ones; freeze the simulator before hand-writing; keep real and synthetic apart.
